# Enterprise ITGC Audit, GRC Assessment & Risk Management Portfolio
As a software developer and cybersecurity professional passionate about secure system architecture, I built this portfolio to demonstrate my ability to bridge technical access controls with enterprise risk management.
**Target Entity:** Apex HealthTech (B2B SaaS Healthcare Analytics)  
**Security & Compliance Frameworks:** SOC 2 Type II, ISO/IEC 27001, HIPAA Security Rule, NIST CSF 2.0  
**Target Roles:** GRC Analyst | IT Auditor | Information Security Associate  

---

## Executive Summary
This portfolio demonstrates an end-to-end Information Technology General Controls (ITGC) audit, network security baseline evaluation, and threat risk assessment for **Apex HealthTech**, a cloud-hosted healthcare software provider processing Electronic Health Records (EHR).

The project simulates technical evaluation across the entire technology stack—mapping Active Directory user governance, PostgreSQL database access, network segmentation, and cloud infrastructure controls directly to business risk and regulatory compliance standards.

---

## Technical Stack & Architecture Overview
* **Cloud Infrastructure:** Amazon Web Services (AWS VPC, Security Groups, IAM, S3)
* **Operating Systems:** Ubuntu Linux (Application Tier), Windows Server (Active Directory / Domain Services)
* **Database Management:** PostgreSQL (Managed, Multi-AZ)
* **Identity & Access Management (IAM):** Windows Active Directory / Azure AD (Entra ID) with Role-Based Access Control (RBAC)
* **Protocols Audited:** HTTPS (443), SSH (22), PostgreSQL (5432), SMB (445), DNS (53), Kerberos/LDAP (88/636)
